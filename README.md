# Credit Scoring: como os dados apoiam a avaliação de risco de crédito

## Sobre o projeto

Caderno temático desenvolvido durante o Bootcamp Bradesco da DIO, utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O projeto explora o conceito de Credit Scoring, o papel dos dados na avaliação de risco de crédito e a aplicação de técnicas de Machine Learning nesse contexto.

## Objetivos

- Compreender o conceito de Credit Scoring;
- Entender como diferentes tipos de dados apoiam a avaliação de risco de crédito;
- Comparar modelos tradicionais de Credit Scoring e abordagens de Machine Learning;
- Identificar os principais desafios relacionados ao uso de dados em decisões de crédito.
